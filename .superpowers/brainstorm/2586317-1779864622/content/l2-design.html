Layer 2: SDK — Design Spec

底层驱动 · 工具集 · 不包含业务逻辑

职责定位

SDK层提供工具和基础设施，不包含管线业务逻辑。所有模块都是"被调用"的工具，不主动编排流程。

关键问题
  1. dashboard.py(4150L) — 用户确认整体保留不分拆。HTTP+SSE+步骤执行耦合在一起，但作为监控系统的完整单元。
  2. memory模块 — 包含进化记忆+自动进化引擎。是否需要对外暴露统一API？
  3. status模块 — fitness追踪跨loop性能变化。和memory的关系？合并还是独立？
  4. mcp+tools — 来自evoscientist_core。哪些是agent_factory真正需要的？

SDK vs 其他层的区分

SDK的职责

  • MCP Server通信
  • Dashboard监控显示
  • 搜索/文献/记忆/状态工具
  • 被L3/L4/L5调用，不主动编排

SDK不做的

  • 管线流程编排 → L3 PES Controller
  • Session生命周期 → L4 Session
  • Agent行为逻辑 → L5 Hyperagents
